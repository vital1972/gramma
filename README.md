# Детектив Ошибкин

Тренажёр русского языка для 4 класса (программа Канакиной–Горецкого) в виде перерыва в игре. Программа живёт в трее Windows. Примерно каждые 15 минут игры в углу экрана вибрирует телефон детектива. Когда ребёнок отпускает мышь и клавиатуру, открывается занятие на 3–5 минут: найти ошибки в записке «Безграмотного», разобрать пропущенные правила, при необходимости решить ещё одно короткое дело.

## Установка

1. Откройте [Releases](https://github.com/vital1972/gramma/releases) и скачайте `DetectiveOshibkin-Setup-<версия>.exe`.
2. Запустите установщик. Windows может показать «Windows защитила ваш компьютер», потому что программа не подписана. Нажмите «Подробнее», затем «Выполнить в любом случае».
3. При первом запуске откроется окно родителя: придумайте PIN из 4–8 цифр. Без PIN ребёнок не сможет поменять настройки, прервать занятие или закрыть программу.

Дальше программа запускается вместе с Windows, а новые версии и новые задания скачивает сама.

## Важно про игры

Окно занятия открывается поверх всех окон, но не может перекрыть игру в режиме **«Полный экран» (exclusive fullscreen)**. В настройках графики игры выберите **«Окно без рамки» / «Borderless window» / «Полноэкранный в окне»**. Выглядит так же, но телефон детектива будет виден.

## Как идёт занятие

- **Телефон.** За 2 минуты до занятия в правом нижнем углу появляется телефон «1 новое сообщение». Клик по нему открывает меню «Прочитать» / «Отложить на 2 минуты». Горячие клавиши, пока телефон на экране: F9 и F10.
- **Отложить** можно один раз перед каждым занятием (настраивается).
- **Старт** только когда ребёнок 7 секунд не трогает мышь и клавиатуру, то есть поставил игру на паузу. Если пауза не наступает 5 минут, телефон предупреждает и через 10 секунд занятие начинается.
- **Дело.** Нажать на слово с ошибкой и исправить. Если все ошибки найдены сразу, занятие окончено. Если нет, детектив разбирает правило, задаёт вопрос и даёт короткое дело на это правило. Дел не больше, чем задано в настройках (1–5).
- **Коины.** Найдена и исправлена ошибка: +15. Найдена, но исправлена неверно: +10. Дело без единой ошибки: +20. Верный ответ на вопрос о правиле: +5. Ложное обвинение верного слова: −3, лупа-подсказка: −5.
- **Отпуск.** Накопив коины (по умолчанию 150), ребёнок может «купить» пропуск одного занятия. Сколько отпусков в день, задаёт родитель.
- **Звания:** Стажёр, Сыщик (300 коинов), Инспектор (800), Старший детектив (1500).
- Правила, в которых ребёнок ошибается, попадаются чаще.

Время, когда программа молчит, можно задать в настройках («Не беспокоить с … до …»). Счёт 15 минут идёт только пока за компьютером кто-то есть: если 2 минуты нет активности, таймер стоит.

## Отчёт в Telegram

1. В Telegram найдите **@BotFather**, отправьте `/newbot`, придумайте имя. BotFather пришлёт токен вида `123456789:AA...`.
2. Найдите своего нового бота и нажмите «Старт» (иначе бот не может вам писать).
3. Узнайте номер своего чата: напишите боту **@userinfobot**, он ответит числом `Id`.
4. В окне родителя вставьте токен и номер, нажмите «Отправить проверочное сообщение».

Отчёт приходит после каждого занятия (можно выключить) и раз в день в заданное время: сколько занятий, сколько ошибок найдено, какие правила слабые. Токен хранится только на этом компьютере.

## Окно родителя

Двойной клик по значку в трее или меню «Настройки и отчёт…». Там отчёт по дням, все настройки, «Открыть дело сейчас», «Прервать занятие», «Проверить обновления», смена PIN, сброс прогресса и выход.

Настройки и прогресс лежат в `%APPDATA%\Детектив Ошибкин\` (`settings.json`, `progress.json`). В репозиторий они не попадают.

## Велоконтроллер

Тренажёр пишет своё состояние в `%ProgramData%\DetectiveOshibkin\state.json` и обновляет его каждые 5 секунд:

```json
{ "version": 1, "state": "idle | warning | session", "phase": "task | rule | result", "session_id": "...", "started_at": "...", "heartbeat": "ISO-время" }
```

Велоконтроллер может ставить свой отсчёт на паузу, пока `state` = `session` и `heartbeat` не старше 15 секунд. Тренажёр, в свою очередь, читает `%ProgramData%\VeloController\state.json` и не начинает занятие, пока там `riding` или `blocking`. Если файлов нет, обе программы работают сами по себе.

## Задания

Все задания в [`content/content.json`](content/content.json). Ошибка в тексте размечается так:

```
{неправильно|правильно:правило:проверка}
```

Например: `Ночью я спрятал {клат|клад:parn:клады} в {лисной|лесной:bezud:лес} избушке.`

Правила: `bezud` безударные гласные, `parn` парные согласные, `neproiz` непроизносимые, `razdel` разделительные Ъ и Ь, `prist` приставка и предлог, `zhishi` ЖИ–ШИ и др., `ship` Ь после шипящих, `capital` большая буква, `comma` запятая при однородных, `slovar` словарные слова.

Чтобы добавить задания: отредактируйте файл прямо на GitHub, **увеличьте `version`** и сохраните в ветку `main`. Программы скачают новый банк в течение 6 часов (или сразу по кнопке «Проверить обновления»). Битый файл программа не возьмёт: проверка `npm test` и сама программа отбрасывают задания с неизвестным правилом или без ошибок.

## Для разработки

```
npm install
npm test        # тесты ядра и проверка банка заданий
npm start       # запуск
npm run demo    # то же, но занятие через 1 минуту игры
```

Новая версия программы: поменяйте `version` в `package.json` (например, на `0.1.1`), затем на GitHub откройте Actions → «Сборка для Windows» → Run workflow, отметьте «Выпустить релиз». Можно и отправить тег `v0.1.1`. GitHub Actions соберёт установщик на Windows и опубликует релиз; установленные программы обновятся сами, когда компьютер 10 минут простаивает без занятия.

Шрифты Neucha и Rubik лежат в `src/renderer/fonts` (лицензия SIL OFL 1.1).
