# Детектив Ошибкин

Тренажёр русского языка для 4 класса (программа Канакиной–Горецкого) и английского (Spotlight 4) в виде перерыва в игре. Программа живёт в трее Windows. Примерно каждые 15 минут игры в углу экрана вибрирует телефон детектива. Когда ребёнок отпускает мышь и клавиатуру, открывается занятие на 2–3 минуты: найти ошибки в записках «Безграмотного» и разобрать пропущенные правила. Сложность и число заданий программа подбирает сама, так чтобы ребёнок отвечал верно в 75–85 % случаев.

## Установка

1. Откройте [Releases](https://github.com/vital1972/gramma/releases) и скачайте `DetectiveOshibkin-Setup-<версия>.exe`.
2. Запустите установщик. Windows может показать «Windows защитила ваш компьютер», потому что программа не подписана. Нажмите «Подробнее», затем «Выполнить в любом случае».
3. При первом запуске откроется окно родителя: придумайте PIN из 4–8 цифр. Без PIN ребёнок не сможет поменять настройки, прервать занятие или закрыть программу.

Дальше программа запускается вместе с Windows, а новые версии и новые задания скачивает сама.

## Важно про игры

Окно занятия открывается поверх всех окон, но не может перекрыть игру в режиме **«Полный экран» (exclusive fullscreen)**. В настройках графики игры выберите **«Окно без рамки» / «Borderless window» / «Полноэкранный в окне»**. Выглядит так же, но телефон детектива будет виден.

## Как идёт занятие

- **Телефон.** За 2 минуты до занятия в правом нижнем углу появляется телефон «1 новое сообщение». Клик по нему открывает меню «Прочитать» / «Отложить на 2 минуты». Горячие клавиши, пока телефон на экране: F9 и F10.
- **Отложить** можно один раз перед каждым занятием (настраивается).
- **Старт** только когда ребёнок 7 секунд не трогает мышь и клавиатуру, то есть поставил игру на паузу. Если пауза не наступает 5 минут, телефон предупреждает и через 10 секунд занятие начинается.
- **Дело.** Нажать на слово с ошибкой и исправить. Если какая-то ошибка ускользнула, детектив разбирает правило, задаёт вопрос и даёт короткое дело на это правило. Дела идут одно за другим, пока занятие укладывается в 2–3 минуты (границы задаются в окне родителя).
- **Сложность** подбирается сама, см. раздел [«Адаптивная нагрузка»](#адаптивная-нагрузка).
- **Коины.** Найдена и исправлена ошибка: +15. Найдена, но исправлена неверно: +10. Дело без единой ошибки: +20. Верный ответ на вопрос о правиле: +5. Ложное обвинение верного слова: −3, лупа-подсказка: −5.
- **Отпуск.** Накопив коины (по умолчанию 150), ребёнок может «купить» пропуск одного занятия. Сколько отпусков в день, задаёт родитель.
- **Звания:** Стажёр, Сыщик (300 коинов), Инспектор (800), Старший детектив (1500), Инспектор угрозыска (3000), Майор сыска (5000), Полковник сыска (8000), Комиссар (12 000 и 7 правил из 10 пойманы уверенно), Легенда сыска (18 000 и все 10 правил). Правило поймано уверенно, если без ошибки не меньше 5 раз и ошибок меньше, чем верных ответов.
- Правила, в которых ребёнок ошибается, попадаются чаще.

Время, когда программа молчит, можно задать в настройках («Не беспокоить с … до …»). Счёт 15 минут идёт только пока за компьютером кто-то есть: если 2 минуты нет активности, таймер стоит.

## Адаптивная нагрузка

Программа держит долю верных ответов ребёнка в коридоре **75–85 %**, а длительность занятия в границах **2–3 минуты**. Уровень сложности и среднее время заданий хранятся в `progress.json` отдельно для русского и английского, поэтому переносятся из занятия в занятие.

- **Что считается ответом.** Ошибка найдена и исправлена с первого раза — верно (1). С подсказкой лупы, со второй попытки или найдена, но исправлена неверно — наполовину (0,5). Пропущена — неверно (0). Ложное обвинение верного слова — неверно (не больше трёх за дело). В английском также слова в радиоперехвате, шифр букв и вопросы к перехвату: верно с первого раза или нет.
- **Как меняется уровень.** Когда на текущем уровне набралось не меньше 6 ответов, считается доля верных среди них (не больше 20 последних). Больше 85 % — уровень выше, меньше 75 % — ниже. После смены счёт начинается заново.
- **Уровни русского** (старт с 4-го, как было раньше):
  1. короткая записка на одно правило (2 ошибки), правило подсказано, лупа бесплатно;
  2. короткая записка;
  3. обычная записка (3 ошибки), детектив подсказывает, на какие правила ошибки;
  4. обычная записка, сказано, сколько ошибок;
  5. записка и короткое дело вместе, 5 ошибок;
  6. то же, но число ошибок не сказано: ребёнок сам решает, когда «Дело закрыто»;
  7. две записки, 6 ошибок, число не сказано.
- **Уровни английского** (старт с 3-го): от 3 картинок и 2 вариантов в записке до 6 картинок, всех ложных вариантов, большего числа слов на повторение, чтения глазами вместо слушания и записок без подсказки о числе ошибок.
- **Объём.** Программа запоминает, сколько секунд у ребёнка уходит на каждый вид задания (скользящее среднее). Пока не прошло 2 минуты, задания идут дальше. После 2 минут следующее задание даётся, только если по прогнозу закончится до 3 минут; если длинное не влезает, а короткое влезает, даётся короткое. В английском после основных шагов идут дополнительные: записка бандита и повторение знакомых слов по очереди.
- **Окно родителя** показывает текущий уровень и точность за последние ответы по каждому предмету, в таблице по дням — точность за день. Отчёт после занятия пишет точность, уровень и длительность в минутах и секундах.

## Английский: дело Интерпола

С версии 0.2.0 занятия по русскому чередуются с английскими. Сюжет: Интерпол просит Ошибкина поймать банду Мистера Микса, которая переписывается по-английски, а ребёнок у детектива переводчик. СМС о таком занятии приходит на телефон с синей плашкой «ИНТЕРПОЛ».

- **Чередование** задаётся в окне родителя, блок «Предметы»: только русский, только английский или по очереди. По умолчанию 2 русских занятия, затем 1 английское. Можно задать отдельную пропорцию на выходные и какой предмет идёт первым. Очередь начинается заново каждый день.
- **Занятие:** новые слова (по умолчанию 2) → «радиоперехват»: услышать слово и выбрать картинку; повторённые слова уже читаются глазами → «шифр букв» на правила чтения → перехват: короткое сообщение банды и 2–3 вопроса по-русски → записка бандита с грамматической ошибкой. Любое слово в тексте можно нажать: прозвучит и покажется перевод.
- **Повторение слов** по коробкам: верный ответ отправляет слово на повтор через 1, 3, 7, 14 и 30 дней, ошибка возвращает его на следующее занятие. Если на повторение накопилось больше 20 слов, новых не дают. Слово считается выученным с 3-й коробки.
- **Главы** идут по модулям Spotlight 4: Лондон (профессии, -s после he/she/it), Нью-Йорк (еда, множественное число), Сидней (зоопарк, am/is/are + -ing), Дублин (семья, have got / has got), Торонто (чувства и места, am/is/are, was/were). Глава закрывается, когда собрано 5 улик (по одной за перехват) и показаны все её слова. После последней главы — «патруль»: повторение по всем главам.
- **Коины** общие с русским, звания разные: у Интерпола Переводчик-стажёр, Агент (20 выученных слов), Спецагент (45), Агент 00Л (70).
- **Озвучка** — встроенный голос Windows, интернет не нужен. Если английского голоса нет: Параметры → Время и язык → Речь → Добавить голоса → English (United States). Без голоса занятие идёт только на чтение.

Английские задания лежат в [`content/english.json`](content/english.json) и обновляются так же, как русские (поднять `version`). Ошибка в записке размечается так: `{неправильно|правильно:правило:ложный вариант}`, например `He {like|likes:ps3:liking} pizza.` Правила: `ps3`, `plural`, `ing`, `have`, `be`. Для каждого английского слова в перехватах и записках нужен перевод в `gloss` или карточка в `words`: `npm test` это проверяет.

## Отчёт родителю

Отчёт приходит после каждого занятия (можно выключить) и раз в день в заданное время: сколько занятий, сколько ошибок найдено, какие правила слабые. Куда его присылать, выбирается в окне родителя: ВКонтакте, MAX или Telegram. Ключи хранятся только на этом компьютере. Результат последней отправки виден в окне родителя под кнопкой проверки.

### ВКонтакте (работает в России без VPN)

1. В ВК откройте «Сообщества» → «Создать сообщество». Подойдёт любой тип, например «Группа по интересам». Название любое, например «Детектив Ошибкин — отчёты».
2. В сообществе: «Управление» → «Сообщения» → включите «Сообщения сообщества».
3. «Управление» → «Работа с API» → «Ключи доступа» → «Создать ключ». Отметьте «Разрешить приложению доступ к сообщениям сообщества», подтвердите и скопируйте ключ.
4. Со своей страницы ВК напишите этому сообществу любое сообщение, например «Привет». Без этого ВК не разрешит сообществу писать вам.
5. В окне родителя (под учётной записью Windows, где играет ребёнок): «Куда присылать» → «ВКонтакте», вставьте ключ, нажмите «Найти мой чат», затем «Отправить проверочное сообщение».

### MAX

Бота в MAX может создать только самозанятый, ИП или организация через business.max.ru, после модерации MAX выдаёт ключ бота. Напишите боту любое сообщение, в окне родителя выберите «MAX», вставьте ключ и нажмите «Найти мой чат». Если проверка пишет про сертификат, установите сертификат Минцифры с gosuslugi.ru/crt.

### Telegram (в России нужен VPN)


1. В Telegram найдите **@BotFather**, отправьте `/newbot`, придумайте имя. BotFather пришлёт токен вида `123456789:AA...`.
2. Найдите своего нового бота и нажмите «Старт» (иначе бот не может вам писать).
3. Узнайте номер своего чата: напишите боту **@userinfobot**, он ответит числом `Id`.
4. В окне родителя вставьте токен и номер, нажмите «Отправить проверочное сообщение».


## Окно родителя

Двойной клик по значку в трее или меню «Настройки и отчёт…». Там отчёт по дням, все настройки, «Открыть дело сейчас», «Прервать занятие», «Проверить обновления», смена PIN, сброс прогресса и выход.

Настройки и прогресс лежат в `%APPDATA%\Детектив Ошибкин\` (`settings.json`, `progress.json`). В репозиторий они не попадают.

## Велоконтроллер

Тренажёр пишет своё состояние в `%ProgramData%\DetectiveOshibkin\state.json` и обновляет его каждые 5 секунд:

```json
{ "version": 1, "state": "idle | warning | session", "phase": "task | rule | result", "session_id": "...", "started_at": "...", "heartbeat": "ISO-время" }
```

Велоконтроллер может ставить свой отсчёт на паузу, пока `state` = `session` и `heartbeat` не старше 15 секунд. Тренажёр, в свою очередь, читает `%ProgramData%\VeloController\state.json` и не начинает занятие, пока там `riding` или `blocking`. Если файлов нет, обе программы работают сами по себе.

## Задания

Все задания в [`content/content.json`](content/content.json). Ошибка в тексте размечается так:

```
{неправильно|правильно:правило:проверка}
```

Например: `Ночью я спрятал {клат|клад:parn:клады} в {лисной|лесной:bezud:лес} избушке.`

Правила: `bezud` безударные гласные, `parn` парные согласные, `neproiz` непроизносимые, `razdel` разделительные Ъ и Ь, `prist` приставка и предлог, `zhishi` ЖИ–ШИ и др., `ship` Ь после шипящих, `capital` большая буква, `comma` запятая при однородных, `slovar` словарные слова.

Чтобы добавить задания: отредактируйте файл прямо на GitHub, **увеличьте `version`** и сохраните в ветку `main`. Программы скачают новый банк в течение 6 часов (или сразу по кнопке «Проверить обновления»). Битый файл программа не возьмёт: проверка `npm test` и сама программа отбрасывают задания с неизвестным правилом или без ошибок.

## Для разработки

```
npm install
npm test        # тесты ядра и проверка банка заданий
npm start       # запуск
npm run demo    # то же, но занятие через 1 минуту игры
```

Новая версия программы: поменяйте `version` в `package.json` (например, на `0.1.1`), затем на GitHub откройте Actions → «Сборка для Windows» → Run workflow, отметьте «Выпустить релиз». Можно и отправить тег `v0.1.1`. GitHub Actions соберёт установщик на Windows и опубликует релиз; установленные программы обновятся сами, когда компьютер 10 минут простаивает без занятия.

Шрифты Neucha и Rubik лежат в `src/renderer/fonts` (лицензия SIL OFL 1.1).
